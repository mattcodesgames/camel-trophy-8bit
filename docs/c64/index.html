FIRE

Controls

  • Joystick: ←↑→↓ and Space for fire. Gamepads work too.
  • Press fire to leave the credits screen, start the game and drop supplies from the plane.
  • Other keys go to the C64 keyboard: Enter = RETURN, Esc = RUN/STOP, F1–F7, PgDn = RESTORE.
  • F9 saves a state, F10 loads it, F12 resets. Fast-forward skips the long decrunch pauses.
  • Stage 1: drop the crate, then steer its parachute onto the black target with the joystick. Stage 2: drive the Land Rover.
